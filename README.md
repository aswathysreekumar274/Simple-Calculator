# Simple Calculator

A simple Python calculator project for beginners. It performs basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division (with zero division handling)

## How to Run
1. Run the file: python calculator.py
2. Enter two numbers when asked
3. See the results instantly

## Technologies Used
- Python
- Basic input/output
